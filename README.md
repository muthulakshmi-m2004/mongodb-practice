# mongodb-practice
 MongoDB Basic Practice Project
 
📌 Overview

This project demonstrates the basic operations of MongoDB including database creation, CRUD operations (Create, Read, Update, Delete), query operators, and a real-world use case implementation.

🎯 Objective

Understand MongoDB fundamentals
Perform CRUD operations
Use query operators
Implement a real-world use case

🛠️ Technologies Used

Node.js
MongoDB
MongoDB Compass
VS Code

➕ CRUD Operations

Insert
Insert one student document
Insert multiple student documents
Read
Fetch all students
Filter students by course
Update
Update one document
Update multiple documents
Delete
Delete one document
Delete all documents (optional)
